# Ghatu Games — sitio web

Sitio estático (HTML + CSS + JS, sin compilación ni librerías externas) para GitHub Pages: repositorio `GhatuGames/GhatuGames.github.io` → https://ghatugames.github.io

- **Juegos y apps:** `data/catalogo.js` (incluye los enlaces de descarga de GitHub Releases)
- **Tutoriales:** `data/tutoriales.js` + archivos Markdown/HTML en `tutoriales/`
- **Guía de edición paso a paso:** [EDITAR-WEB.txt](EDITAR-WEB.txt)

Vista previa local: `python3 -m http.server 8000` → http://localhost:8000

Publicación: Settings → Pages → Deploy from a branch → `main` / root.
